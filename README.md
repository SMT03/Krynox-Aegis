# 🛡️ Krynox Aegis: Zero-Trust Solana Keypair Sentinel

**Krynox Aegis** is an enterprise-grade, kernel-level security suite designed to protect Solana developers from credential theft and supply-chain attacks. By leveraging eBPF-LSM hooks, it synchronously blocks unauthorized access to sensitive private keys and generates immutable forensic reports on the Solana Devnet.

![Krynox Banner](krynox-ui/public/Gemini_Generated_Image_5lnmiv5lnmiv5lnm-removebg-preview.png)

## ⚡ Core Features

- **Kernel-Level Protection**: Uses eBPF-LSM to intercept `security_file_open` syscalls. Malicious processes are terminated with `SIGKILL` before they can read a single byte.
- **AI-Driven Forensics**: Real-time forensic reports generated by **Llama-4 Scout** via Groq AI, analyzing attack vectors and MITRE ATT&CK mapping.
- **Blockchain Audit Logs**: Every blocked threat is hashed and permanently logged to the **Solana Devnet** using the SPL Memo program.
- **Cyber-Tech Dashboard**: A high-fidelity React dashboard featuring live threat feeds (with Markdown support), system status monitoring, and log exports.
- **Masquerading Defense**: Defeats symlink evasion by resolving VFS-layer dentries in kernel-space.

## 🛠️ Technology Stack

- **Kernel**: C (eBPF), BCC (BPF Compiler Collection)
- **Backend**: Python 3, FastAPI, Uvicorn, LangChain (Groq AI)
- **Blockchain**: Solana Web3.py (`solders`, `solana-py`)
- **Frontend**: React 18, Vite, Tailwind CSS v4, Framer Motion, Lucide React
- **Notifications**: Linux `notify-send` (Desktop Alerts)

## 🚀 Getting Started

### Prerequisites
- Linux Kernel 5.10+ (with BTF enabled)
- `bcc-python` and `python3-devel` installed via your package manager (e.g., DNF/APT).
- A valid `GROQ_API_KEY` in a `.env` file.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/SMT03/Krynox-Aegis.git
   cd Krynox-Aegis
   ```
2. Install Python dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the Sentinel (requires root):
   ```bash
   sudo python3 sentinel.py
   ```
4. Launch the Dashboard:
   ```bash
   cd krynox-ui
   npm install
   npm run dev
   ```
